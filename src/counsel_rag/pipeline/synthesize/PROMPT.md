# synthesize 표준 프롬프트

종합 서브에이전트(T7·T8 등)를 기동할 때 이 파일 내용을 그대로 지시문에 포함시킨다.
컨트롤러(상위 태스크)가 카테고리/주제와 입력 소스 발췌를 채워 넣는다.

---

당신은 **[카테고리/주제]**의 종합 지식 문서를 작성한다.

**입력**: `corpus/atomic/`의 관련 소스 발췌 (컨트롤러가 지정한다)
**출력**: `knowledge/<대상>/<slug>.md` 1개

## 집필 규칙 (전부 강제)

1. 원문 문장을 그대로 옮기지 마라 — 방법론과 원칙을 당신의 문장으로 재기술한다
2. 특정 전문가의 고유 명명(예: 시그니처 이론명)은 일반 언어로 풀어 써라. 내용은 보존한다
3. 소스 2개 이상을 종합하라. 하나뿐이면 frontmatter에 그 사실을 note로 남겨라
4. 각 `##` 섹션은 혼자 읽혀도 완결: 상황 → 원칙 → 구체적 방법이 한 섹션 안에 있어야 한다
5. "위에서 말했듯" 류 상호참조 금지 — 섹션이 조각으로 검색 결과에 단독 반환돼도 성립해야 한다
6. `## 상황을 좁히는 질문` 섹션 필수 — 소스의 "이런 경우인지 먼저 봐야" 구분법을 질문으로 추출한다
7. frontmatter: `reviewed: false` 고정, `sources`는 `src-NNN` 코드만 (실제 소스명 금지)
8. 채널·전문가·프로그램 실명 절대 금지 (본문·주석 포함)
9. 문서의 기본 청자는 양육자다 — "아이가 ~할 때 (양육자가) 이렇게 한다" 화법을 쓴다. 당사자
   본인 화법("나는 ~할 때 이렇게 한다" 등)은 쓰지 않는다

작성 후 `validate.py`를 실행해 통과를 확인하고, 위반이 있으면 스스로 고쳐라.

```bash
uv run python -m counsel_rag.pipeline.synthesize.validate knowledge/<대상>/<slug>.md
```

기계 검증은 형식·금칙만 잡는다. 내용 정확성·조각 완결성 같은 판단은 여기서 걸러지지
않으므로, 통과했다고 해서 검수(G2)를 생략할 수 있는 것은 아니다 — `checklist.md` 참고.
